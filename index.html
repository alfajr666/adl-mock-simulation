Methodology and model boundary

The engine uses exact rational arithmetic for a single paired linear market. Equity is collateral plus signed unrealized PnL at the frozen mark. Insurance pays the calculated deficit first; any remaining quantity settles at the default position's bankruptcy price. The queue is frozen before ADL matching and is ranked by either the reference profit-weighted score or the experimental leverage-only score.

This release does not infer a live exchange queue, cross-margin risk, order-book execution, fees, funding, or a personal account's safety. Every scenario is synthetic and reproducible.
